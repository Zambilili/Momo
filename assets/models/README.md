# Modèles 3D

Aucun fichier de modèle externe n'est utilisé : l'ordinateur portable, la carte mère,
le processeur, la barrette de mémoire, le SSD, les engrenages, le bouclier, le disque
et l'écran sont **construits par code** avec Three.js (voir `js/scene-kit.js`,
`js/animations3d.js` et `js/services3d.js`).

Avantages : aucun téléchargement lourd, aucune licence tierce, rendu net à toute taille.

Si vous ajoutez plus tard un modèle (.glb), placez-le ici et notez sa source et sa licence
(par exemple CC0 ou CC-BY) dans ce fichier.
